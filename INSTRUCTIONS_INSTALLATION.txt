ÉTAPE 7: CRÉER UN SITE DE TEST
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Dans Web Station, cliquez sur "Portail Web" → "Créer"

2. Configurez:
   - Type: Hôte virtuel basé sur le port
   - Nom: test-php83
   - Port HTTP: 8088 (ou un autre port libre)
   - Dossier racine: /volume1/web/test-php83
   - ⭐ Backend server: Sélectionnez "PHP 8.3"

3. Cliquez sur "OK"

4. Créez un fichier de test (dans le terminal SSH):

   sudo mkdir -p /volume1/web/test-php83
   sudo tee /volume1/web/test-php83/index.php << 'EOF'
   <?php
   phpinfo();
   ?>
   EOF
   sudo chown -R http:http /volume1/web/test-php83

5. Ouvrez dans votre navigateur:
   http://192.168.1.47:8088/

   ✅ Vous devez voir:
   - PHP Version 8.3.8
   - Server API: FPM/FastCGI
   - Configuration File: /var/packages/php83/target/conf/php.ini
   - Liste des extensions chargées
